Changelog

v2.2.0 (2026-10-24)

New

Site search for your static site. Turn on Site search in ShipStatic → Settings, then Process and Sync, and the search boxes on your static site start working. Results appear as you type, with the matching words highlighted, and you can move through them with the keyboard. Everything runs in the visitor's browser, so there's no server or outside service to set up. Each destination gets its own search, matching its own text changes and address. Your live WordPress site keeps its normal search.

New

A ShipStatic Search element for Bricks that you can style down to the last detail: the box, the input, the button and icons, the label, and the results list, including each result, the selected result, titles, snippets, the highlighted words and the "no results" message. While you edit, the builder shows sample results so you can style them in place. Not using Bricks? Add the same search box with the [shipstatic_search] shortcode.

Improved

Pages with a search box are no longer flagged as having a feature that won't work on the static site when Site search is on.
