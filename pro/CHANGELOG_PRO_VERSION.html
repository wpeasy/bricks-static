Changelog

v1.0.4 (2026-07-10)

New

Bricks Static Pro unlocks every limit in the free plugin — unlimited pages per sync, unlimited destinations, unlimited media/link/video replacements, and full gzip output — and adds its own extra features on top, like remote pruning, sitemap generation, and licensed automatic updates. Everything below is included when Pro is active alongside the free plugin.

New

Export ZIP downloads (the free plugin's new feature) now include Pro's gzip-compressed files and the fuller server config that serves them, plus a sitemap.xml and robots.txt — matching exactly what a real sync would push to your destination. If your server's PHP doesn't support gzip compression, you'll see a clear notice instead of the download silently missing files.

Bricks Static Pro requires the free Bricks Static plugin. Its changelog is published at https://brxprod.com/bricks-static-changelog/
