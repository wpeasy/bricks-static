Changelog

v1.0.0 (2026-06-21)

New

Bricks Static Pro unlocks every limit in the free plugin — unlimited pages and destinations, all replacement types, and gzip output — and adds extra tooling on top (remote pruning, sitemaps, and licensed automatic updates). Everything below is included when Pro is active alongside the free plugin.

New

Unlimited pages per sync — the free plugin renders up to 10, Pro removes the cap.

New

Unlimited destinations with "sync all", so you can publish the same build to staging, production, CDN origins and more from one click.

New

Advanced per-destination replacements: swap Media (images and videos, with responsive variants rebuilt), rewrite Links and video embeds, and change the values of data-* attributes.

New

Gzip pre-compression ships .gz versions of your files plus the matching server rules, for faster delivery.

New

Remote pruning automatically removes files from the destination that no longer exist locally.

New

Sitemap.xml and robots.txt are generated and pointed at each destination's own domain.

New

License activation with automatic updates, plus a short grace period if a renewal is late.

Bricks Static Pro requires the free Bricks Static plugin. Its changelog is published at https://brxprod.com/bricks-static-changelog/
