# Changelog

## v2.1.6 (2026-10-23)

### New
Publish one site to several places at different addresses. Each destination now gets links for its own address, so the same site can go to two GitHub project sites, or a project site and your own domain, and every page keeps its styles and images. Text, image, link and video replacements still apply per destination, so each copy can differ where you choose.

### Improved
After updating, press Process once so the site is prepared in the new way.

### Fixed
Removing a destination now removes everything the plugin kept for it.
